# Instructions for future Codex sessions

Before coding, read `project_management/MASTER_PLAN.md`, `TASKS.md`, `PROGRESS.md`,
`DECISIONS.md`, and `HANDOFF.md`.

- Preserve the approved architectural contracts documented in `docs/` and `DECISIONS.md`.
- Implement one phase at a time; do not start a later phase without an explicit request.
- Run relevant tests instead of assuming success. Never claim unexecuted tests passed.
- Update project memory after every phase and record truthful outcomes.
- Mark tasks complete only after verification.
- Record unresolved defects and exact next steps in project memory.
- Avoid unnecessary dependencies and prioritize deadline-critical functionality.
- Do not modify historical migrations or committed workflow versions to represent rule changes.
- Never perform destructive operations without approval.
